# PRIO

Right request. Right priority. Right team.

Proyecto individual de AI Engineering para clasificar y priorizar
solicitudes de soporte de huéspedes y anfitriones mediante LLMs.

## La idea

Un botón de ayuda asociado a una reserva permite enviar texto o voz.
PRIO propone una categoría, urgencia, resumen y equipo responsable.
Un agente humano revisa la propuesta antes de su registro final.

## Estado

En desarrollo. Estructura inicial del proyecto.

## Tecnologías previstas

- FastAPI y Pydantic.
- LLM local mediante Ollama y LLM externo mediante API.
- Streamlit para la interfaz y el dashboard.
- Pytest para las pruebas automáticas.
- Transcripción de voz como funcionalidad diferencial.
