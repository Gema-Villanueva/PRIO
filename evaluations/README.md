# Evaluación de PRIO

Compararemos el modelo local y el externo utilizando los mismos casos
y las mismas clasificaciones de referencia.

## Métricas previstas

- Calidad de clasificación: categoría, urgencia y departamento.
- Porcentaje de respuestas que cumplen el esquema de Pydantic.
- Tiempo de respuesta.
- Tokens de entrada y salida.
- Coste estimado por solicitud.

Los casos usados para la evaluación final se mantendrán separados
de los ejemplos incluidos en los prompts.
